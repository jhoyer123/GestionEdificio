# Sistema de Gestión de Edificios

Plataforma integral para la **gestión de edificios**, que centraliza la administración de residentes, personal, áreas comunes, reservas, pagos y comunicación interna.

El proyecto está organizado como un **monorepo**, incluyendo:
- **Frontend Web**
- **Backend API**
- **Aplicación Mobile (EXPERIMENTAL)** 

Cada módulo cumple una función específica y se comunica de forma segura mediante una API REST.

---

## ✨ Funcionalidades Principales
- Gestión de usuarios, residentes y personal
- Sistema de roles y permisos (un usuario puede tener múltiples roles)
- Gestión de áreas comunes
- Reservas con simulación de pagos
- Generación de facturas de mantenimiento
- Anuncios segmentados por rol
- Autenticación segura con verificación en dos pasos (2FA)
- Dashboard administrativo con métricas
- Comunicación completa entre frontend, backend y mobile mediante API REST
